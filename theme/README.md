# Thème Shopify Ardent

Ce dossier contient une copie du thème brouillon **Ardent V2 Premium** de la boutique Shopify Ardent, récupérée le 24 septembre 2026. Le thème publié au moment de la copie était **Shopistart**.

Le code est organisé selon la structure native Shopify (`assets`, `blocks`, `config`, `layout`, `locales`, `sections`, `snippets`, `templates`). Les modifications du site se préparent ici et se vérifient sur un thème brouillon avant toute mise en ligne.

Les visuels de montre et les textes commerciaux doivent être contrôlés avec [Product Truth](../docs/product-truth.md). Les décors élémentaires sont illustratifs ; ils ne prouvent aucune caractéristique technique de la montre.
