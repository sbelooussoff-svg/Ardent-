# Sources maîtresses Ardent

- [Brand Bible v1.0](brand-bible.md) — identité et voix de marque.
- [Product Truth v2.0](product-truth.md) — faits produit et données à vérifier.

Les choix visuels marqués comme propositions restent à valider avant leur mise en production.
