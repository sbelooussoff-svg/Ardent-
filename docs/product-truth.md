# 3. Gestion des prix

Un prix n’est jamais considéré comme permanent.

Il doit être interprété comme :

**prix observé + fournisseur + date + conditions**

Exemple :

> NH35 — 19,00 € — Love Go Buy — observé le 23/09/2026 — frais de port non inclus.

Lorsqu’un prix change, conserver idéalement son historique plutôt que d’écraser silencieusement l’ancienne valeur.

# 13. Règle pour le configurateur

Le configurateur ne doit présenter que :

- les composants actifs ;
- les variantes réellement proposées ;
- les combinaisons techniquement compatibles.

Le packaging, les coûts internes ou les composants invisibles pour le client restent dans la base interne mais ne doivent pas apparaître comme options.

---

# 14. Règle pour les images IA

Une image générée n’est jamais une preuve technique.

Si un rendu IA et le produit réel diffèrent :

**le produit réel est la référence.**

Cela est particulièrement important pour :

- proportions ;
- cadrans ;
- logo ;
- aiguilles ;
- trous centraux ;
- couleurs ;
- bracelet ;
- couronne ;
- mouvement.

---

# 15. Hiérarchie de confiance

1. mesure ou test réalisé par Ardent ;
2. documentation fabricant ;
3. information explicitement confirmée par les fondateurs ;
4. fournisseur actuel ;
5. source externe fiable ;
6. estimation.

Une estimation ne doit jamais être affichée comme caractéristique officielle.

---

# 16. Données historiques

Les anciens fournisseurs et anciens prix présents dans les conversations ou dans Notion peuvent être conservés comme historique.

Ils ne doivent plus être utilisés comme données commerciales actuelles sans nouvelle validation.

---

# 17. Règle finale

**Une donnée manquante est acceptable. Une donnée fausse ne l’est pas.**

Lorsque l’information n’est pas certaine :

**À VÉRIFIER.**
