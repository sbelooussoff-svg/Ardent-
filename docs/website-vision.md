# ARDENT — WEBSITE VISION

**Statut : source maîtresse de l’expérience digitale**  
**Version : 2.0 — Elemental Experience**

---

# 1. Concept central

Le site Ardent repose sur une idée visuelle forte :

**chaque collection possède son propre élément.**

### Méridian
**FEU**

Volcan, roche noire, chaleur, braises, lave, lumière rouge/orange, fumée et énergie.

### Bastille
**EAU**

Océan, profondeur, lumière sous-marine, vague, particules, reflets, mouvement liquide.

### Élysée
**AIR / CIEL**

Nuages, lumière, altitude, horizon, atmosphère, ciel profond puis éventuellement espace.

Ces éléments ne sont pas de simples arrière-plans.

Ils deviennent le langage visuel permettant d'identifier instantanément chaque collection.

---

# 2. Principe créatif

Le concept doit être :

**immersif mais luxueux.**

Jamais :

- jeu vidéo ;
- parc d'attractions ;
- démonstration d'effets spéciaux ;
- interface surchargée ;
- animation agressive.

Les éléments naturels doivent mettre la montre en valeur.

**La montre reste toujours le héros.**

---

# 3. Header global

Le header conserve la structure Ardent actuelle.

### Gauche
Menu hamburger.

### Centre
Logo ARDENT.

### Droite
Recherche.

Panier.

Éventuellement compte client ultérieurement.

Le header est superposé aux environnements.

Il peut adapter légèrement sa couleur selon le contraste du décor mais conserve toujours une identité cohérente.

Style :

minimaliste, transparent ou légèrement translucide, extrêmement discret.

---

# 4. Homepage — Hero Elemental Carousel

L'arrivée sur Ardent doit produire un impact immédiat.

Le hero occupe pratiquement tout le viewport.

Il représente une sorte de **plateforme / carrousel tridimensionnel composé de trois univers**.

Les univers ne changent jamais brutalement.

Ils semblent appartenir à un même espace qui tourne.

---

## SCÈNE 01 — MÉRIDIAN / FEU

Une Méridian apparaît dans un environnement volcanique premium.

Pas une énorme explosion.

Ambiance recherchée :

roche sombre ;

lumière venant de lave hors champ ;

petites braises ;

fumée lente ;

légères projections ;

reflets chauds sur la montre ;

mouvement atmosphérique constant.

La montre doit rester très nette.

### Texte

**MÉRIDIAN**

Hook possible :

**Née dans l'intensité.**

ou

**L'intensité prend forme.**

### Actions

**Découvrir la collection**

**Configurer la mienne**

---

# 5. Transition Feu → Eau

Après environ :

**4 secondes**

le changement commence.

Durée cible :

environ **1 à 1,5 seconde**.

Le monde ne disparaît pas.

La structure tourne.

La lumière chaude glisse progressivement hors champ.

La fumée devient brume.

Les particules deviennent gouttelettes.

La palette refroidit progressivement.

Puis Bastille arrive.

L'objectif est que le visiteur ait l'impression de regarder tourner un immense objet scénique possédant plusieurs faces.

---

# 6. SCÈNE 02 — BASTILLE / EAU

Bastille apparaît dans un univers océanique.

Pas de décor tropical ou touristique.

L'ambiance doit rester profonde et sophistiquée.

Éléments possibles :

rayons lumineux traversant l'eau ;

particules très fines ;

ondulation ;

reflets liquides sur le métal ;

légère présence de profondeur ;

mouvement lent de l'eau.

Éventuellement quelques silhouettes marines très discrètes.

La montre reste parfaitement lisible.

### Texte

**BASTILLE**

Hook possible :

**Façonnée par les profondeurs.**

ou

**Sous la surface, le caractère.**

### Actions

**Découvrir la collection**

**Configurer la mienne**

---

# 7. Transition Eau → Air

La caméra / plateforme continue son déplacement.

L'eau devient progressivement plus lumineuse.

Les bulles deviennent particules atmosphériques.

La scène semble remonter vers la surface.

La lumière blanche augmente.

Puis le ciel apparaît.

---

# 8. SCÈNE 03 — ÉLYSÉE / AIR

Élysée apparaît dans un environnement extrêmement lumineux et aérien.

Nuages volumétriques.

Ciel profond.

Lumière naturelle élégante.

Mouvements extrêmement lents.

La caméra peut donner l'impression de flotter légèrement.

### Texte

**ÉLYSÉE**

Hook possible :

**Au-dessus du temps.**

ou

**L'élégance prend de la hauteur.**

### Actions

**Découvrir la collection**

**Configurer la mienne**

---

# 9. Boucle du hero

Après Élysée :

Air → chaleur lumineuse → fumée → retour au feu.

Le cycle doit pouvoir tourner indéfiniment.

L'utilisateur peut également changer manuellement de collection.

Desktop :

petits indicateurs extrêmement discrets.

Mobile :

swipe horizontal possible.

Les animations automatiques doivent s'arrêter lorsqu'un utilisateur commence à interagir avec le hero.

---

# 10. Technologie média du hero

Les univers peuvent être construits avec une combinaison de :

- vidéo générée puis montée ;
- WebGL ;
- particules temps réel ;
- gradients animés ;
- textures ;
- overlays ;
- profondeur CSS ;
- shaders lorsque pertinent.

Les fonds feu/eau/ciel peuvent notamment être préparés avec des outils comme **Higgsfield Cinema Studio Video ou Seedance**, puis compressés pour le web.

Ils ne doivent pas être générés à chaque visite.

Ils deviennent des assets optimisés du site.

La montre réelle peut être compositée par-dessus pour garantir une fidélité parfaite.

---

# 11. Après le hero

Le site ne doit pas devenir une succession de rectangles e-commerce après une introduction spectaculaire.

La narration continue.

# 18. Menu — Collections

Lorsque l'utilisateur survole ou sélectionne :

**Collections**

trois sous-parties apparaissent latéralement.

### Méridian

Image spécifique dans son univers feu.

### Bastille

Image spécifique dans son univers eau.

### Élysée

Image spécifique dans son univers air.

Les visuels doivent être différents du hero tout en appartenant au même univers artistique.

Un clic ouvre directement la collection correspondante.

---

# 19. Menu — Configurateur

Même logique.

Trois choix :

**Configurer une Méridian**

**Configurer une Bastille**

**Configurer une Élysée**

Avec pour chacun une image correspondant à son élément.

Chaque lien ouvre directement le configurateur de cette collection.

---

# 20. Menu — Langue

Le menu contient un sélecteur discret :

**FR / EN**

Pas de gros drapeau.

---

# 21. Page COLLECTION — principe général

Lorsque l'utilisateur choisit une collection, il entre dans son élément.

La navigation est basée sur une expérience de scroll scénarisée.

La scène reste partiellement fixe tandis que le scroll fait évoluer :

l'environnement ;

la profondeur ;

la caméra ;

la montre ;

le contenu.

---

# 22. Collection Bastille — descente

Le visiteur commence près de la surface de l'eau.

Première configuration présentée.

Scroll.

La caméra descend.

La lumière venant de la surface diminue légèrement.

Deuxième configuration.

Scroll.

Descente plus profonde.

Troisième configuration.

La scène devient plus mystérieuse.

Le mouvement doit rester extrêmement lent et élégant.

On ne doit jamais donner l'impression d'un jeu sous-marin.

---

# 23. Collection Méridian — progression volcanique

Le visiteur commence dans un environnement rocheux sombre.

Première configuration.

Puis le scroll rapproche progressivement le visiteur d'une zone volcanique plus intense.

Les couleurs deviennent plus chaudes.

La quantité de braises augmente subtilement.

Deuxième configuration.

Puis troisième configuration.

La dernière étape peut se dérouler devant une immense lumière volcanique hors champ.

Pas besoin d'explosion.

La montée de l'intensité suffit.

---

# 24. Collection Élysée — ascension

Début :

ciel et nuages.

Première configuration.

Scroll.

Montée en altitude.

Deuxième configuration.

Scroll.

Stratosphère.

Troisième configuration.

À la fin, possibilité d'atteindre :

un ciel extrêmement sombre ;

la courbure subtile de la Terre ;

ou un environnement proche de l'espace.

La transition doit rester élégante et réaliste.

---

# 25. Fin du scroll collection

Lorsqu'il n'y a plus de configuration :

le scroll narratif s'arrête naturellement.

Une section finale apparaît :

**Créer votre version**

CTA :

**Configurer cette collection**

Puis le footer.

L'utilisateur ne doit jamais se retrouver dans un scroll artificiellement bloqué sans comprendre pourquoi.

---

# 26. Configurateur — principe général

Lorsque l'utilisateur arrive dans un configurateur :

il a déjà choisi sa collection.

Il ne choisit donc pas à nouveau Bastille / Méridian / Élysée.

Il personnalise directement la montre.

---

# 27. Configurateur Méridian

Environnement :

**volcan actif premium.**

Arrière-plan animé :

fumée ;

lave distante ;

petites projections ;

lumière chaude ;

braises.

La montre reste stable au premier plan.

L'environnement ne doit jamais masquer les couleurs réelles du cadran ou du boîtier.

---

# 28. Configurateur Bastille

Environnement :

**fonds marins.**

Éléments :

mouvement d'eau ;

reflets ;

particules ;

ondulation ;

quelques poissons très éloignés et extrêmement subtils.

Pas d'aquarium.

Pas de décor enfantin.

---

# 29. Configurateur Élysée

Environnement :

**ciel en mouvement.**

Les nuages passent lentement derrière la montre.

La lumière évolue doucement.

L'impression peut être celle d'une rotation extrêmement lente de l'atmosphère.

---

# 30. Interface configurateur

La montre domine l'écran.

Les contrôles doivent être minimalistes.

Desktop :

visuel principal dominant.

Contrôles placés latéralement ou sous le produit selon largeur disponible.

Mobile :

montre en haut.

Contrôles en bottom sheet.

---

# 31. Étapes configurateur

Selon les composants réellement disponibles :

**Boîtier**

**Cadran**

**Aiguilles**

**Mouvement**

puis éventuellement :

**Bracelet**

**Options**

Chaque étape utilise de grandes miniatures propres.

Pas de longs menus déroulants.

---

# 32. Changement de composant

Lorsque le client change une pièce :

pas de flash.

Pas de remplacement brutal.

Utiliser une courte transition.

Exemple :

cadran actuel disparaît légèrement ;

nouveau cadran apparaît ;

reflet très subtil ;

retour immédiat au produit.

Durée :

environ 200–500 ms selon effet.

---

# 33. Réalisme produit

Les environnements peuvent être très créatifs.

**La montre, elle, doit rester exacte.**

Cela signifie :

- vraies couleurs ;
- bonnes proportions ;
- bonnes aiguilles ;
- bon cadran ;
- bon boîtier ;
- bon bracelet ;
- bonne position des composants.

La fidélité produit gagne toujours contre l'esthétique.

---

# 34. 3D

Objectif final :

une vraie montre interactive en 3D.

Technologies possibles :

GLB / glTF.

Three.js ou moteur équivalent.

PBR.

Textures optimisées.

Rotation libre contrôlée.

Zoom limité.

La 3D doit être suffisamment légère pour fonctionner correctement sur mobile.

---

# 35. Usage de Higgsfield pour la 3D

Higgsfield permet notamment de générer ou préparer des GLB et d'effectuer des opérations de remesh.

Cela peut servir :

aux décors ;

aux expérimentations ;

aux prototypes ;

à certains assets environnementaux.

Pour les montres vendues :

une reconstruction IA depuis une simple photo ne doit pas être considérée automatiquement comme suffisamment fidèle.

La géométrie définitive du produit doit être validée par rapport aux véritables composants Ardent.

---

# 36. Génération des univers avec Higgsfield

Pour les environnements cinématiques, les outils pertinents comprennent notamment :

**Cinema Studio Video**

pour compositions cinématographiques et mouvements maîtrisés.

**Seedance**

pour séquences ou boucles utilisant plusieurs références.

Ces outils peuvent produire les rushs élémentaires.

Ensuite :

montage ;

compression ;

bouclage ;

optimisation web.

L'environnement final chargé sur Shopify doit être un média optimisé et non un appel permanent à un modèle IA.

---

# 37. Desktop vs Mobile

Desktop peut proposer :

- parallaxe ;
- transitions plus profondes ;
- mouvements caméra ;
- interaction curseur ;
- scroll narratif.

Mobile doit préserver :

- univers ;
- mouvement ;
- immersion ;
- qualité visuelle.

Mais simplifier :

- particules ;
- vidéos ;
- shaders ;
- résolution ;
- profondeur des animations.

L'expérience mobile ne doit pas essayer de reproduire chaque effet desktop.

---

# 38. Reduced Motion

Si le système de l'utilisateur demande moins d'animations :

le site doit rester totalement fonctionnel.

Les scènes deviennent plus statiques.

Les transitions sont réduites.

Aucun contenu essentiel ne dépend du mouvement.

---

# 39. Performance

L'expérience Ardent doit sembler chère parce qu'elle est fluide.

Pas parce qu'elle charge énormément d'effets.

Principes :

- lazy loading ;
- vidéo WebM/MP4 optimisée ;
- poster frames ;
- responsive media ;
- preload uniquement pour scène initiale ;
- chargement différé des deux autres univers ;
- textures compressées ;
- modèles 3D optimisés ;
- limitation des particules mobile ;
- aucun moteur inutile en arrière-plan.

---

# 40. Rythme général

Le site alterne volontairement :

**WOW**

hero élémentaire.

↓

**CALME**

produit.

↓

**IMMERSION**

collections.

↓

**CALME**

savoir-faire.

↓

**INTERACTION**

configurateur.

Cette alternance est essentielle.

Si chaque section est spectaculaire, plus aucune ne l'est.

---

# 41. Règle créative

Le site doit faire penser :

**« Je n'ai jamais vu une marque de montres présenter ses collections exactement comme ça. »**

Mais jamais :

**« Ils ont simplement ajouté beaucoup d'effets à Shopify. »**
